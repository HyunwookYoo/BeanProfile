블렌드 OCR 실기기 테스트 카드 — 설계

상태: 사용자 승인 완료 산출물: docs/mockups/ocr-blend-test-cards.html

1. 목적

BeanProfile 앱의 사진 OCR을 실기기에서 검증할 수 있도록, 다른 화면에 띄운 뒤 휴대폰 카메라로 촬영하는 블렌드 커피 정보 카드 HTML을 만든다.

이 산출물은 앱 UI나 신규 기능이 아니다. Flutter 코드, OCR 파서, 데이터 모델은 변경하지 않는다.

2. 범위

하나의 독립 HTML에 다음 두 테스트 카드를 제공한다.

  1. B — 실제형 2열 카드
  2. 상용 커피 카드에 가까운 시각적 위계
  3. 두 구성 원두를 좌우 열로 명확히 구분
  4. 제품·로스터리·로스팅·컵노트는 공통 영역에 배치
  5. C — 고밀도 스트레스 카드
  6. 더 작은 글자와 촘촘한 정보 밀도
  7. 라벨과 값이 반복되는 표 구조
  8. 장식 요소와 보조 문구를 포함하되, 정답 데이터는 B와 동일

각 카드는 밝은 배경과 어두운 저대비 배경을 전환할 수 있다. 카드만 크게 표시하는 전체화면 기능도 제공한다.

3. 공통 정답 데이터

두 카드와 모든 대비 상태는 같은 정보를 표시한다. 이를 통해 레이아웃과 대비만 바뀌었을 때 OCR 결과를 비교할 수 있다.

4. 화면 구성

상단 제어 영역

  • 카드 선택: B 실제형 / C 스트레스형
  • 대비 선택: 밝은 배경 / 어두운 저대비
  • 카드만 전체화면 버튼
  • 현재 카드와 대비 상태 표시

제어 영역은 촬영 대상 카드 바깥에 둔다. 전체화면에서는 카드만 표시하고, 화면 탭 또는 Esc로 돌아올 수 있게 한다.

B — 실제형 2열 카드

  • 상단: 로스터리, 제품명, BLEND
  • 중앙: 구성 1과 구성 2를 같은 폭의 두 열로 배치
  • 각 열: 국가와 비율을 가장 크게, 지역과 가공을 그 아래 배치
  • 하단: 로스팅 단계·날짜와 컵노트
  • 구성 간 경계를 충분히 주어 좌표 기반 라벨-값 매칭의 기준 카드로 사용

C — 고밀도 스트레스 카드

  • 상단: 작은 로스터리 표기와 큰 제품명
  • 중앙: 구성 행을 반복 표 형태로 배치
  • 국가·지역·가공·비율 라벨과 값을 서로 다른 열에 배치
  • 보조 문구와 얇은 구분선을 추가해 실제 포장지의 정보 밀도를 모사
  • 필수 데이터의 글자 크기는 촬영 가능한 범위로 유지하며, 의도적인 회전·왜곡은 넣지 않는다

5. 대비 상태

밝은 배경

  • 따뜻한 아이보리 카드와 짙은 에스프레소 글자
  • 기준 OCR 결과를 얻는 정상 대비 상태

어두운 저대비

  • 짙은 차콜 카드와 가까운 명도의 회색 글자
  • 기존 assets/test/ocr_dark_blend_en.png와 유사하게 OCR 전처리 필요성을 검증
  • 모든 글자를 완전히 숨기지는 않고, 육안으로는 읽을 수 있지만 카메라 노출에 따라 누락될 수 있는 수준으로 설정

6. 반응형과 사용성

  • 카드 비율은 기존 테스트 픽스처와 같은 3:4를 유지한다.
  • 데스크톱에서는 카드가 화면 높이에 맞춰 최대한 크게 표시된다.
  • 좁은 화면에서는 제어 영역이 줄바꿈되고 카드가 가로폭에 맞게 축소된다.
  • 외부 폰트, 이미지, CDN을 사용하지 않는 단일 파일로 만든다.
  • 버튼은 마우스와 터치 모두 사용할 수 있어야 한다.

7. 검증

  • HTML 문법과 로컬 로딩을 확인한다.
  • 데스크톱 및 모바일 크기에서 카드가 잘리지 않는지 렌더링한다.
  • B/C, 밝음/어두움의 네 조합이 동일한 정답 데이터를 표시하는지 확인한다.
  • 전체화면 진입과 복귀를 확인한다.
  • 기존 앱 코드와 테스트 자산이 변경되지 않았는지 Git diff로 확인한다.

8. 비목표

  • Flutter 앱의 입력 폼이나 화면 변경
  • OCR 파서·전처리 알고리즘 수정
  • 새로운 PNG 픽스처 생성
  • 실제 상용 브랜드의 디자인 복제
  • 자동 촬영, 카메라 제어 또는 OCR 결과 수집
